# Sistema de Gestión Universitaria

## Descripción

Este programa fue desarrollado en Python y simula un sistema de gestión universitaria. 
Permite registrar estudiantes, profesores y cursos.

## Funcionalidades

- Registrar estudiantes
- Registrar profesores
- Crear cursos
- Matricular estudiantes
- Calcular promedio de notas
- Mostrar estudiantes de un curso
## Explicación de la solución

El programa utiliza programación orientada a objetos para representar estudiantes, profesores y cursos.

## Ejemplos de uso 
Ejemplo:

Registrar estudiante:
Nombre: Matilda
ID: 092

Salida:
Estudiante registrado correctamente.
